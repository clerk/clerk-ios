## Shared defect found and fixed

The old `_baseMutate` passed successful deletion receipts (`deleted: true` with only object/ID) into `fromJSON`. That overwrote required email, phone and external-account fields with missing values. Native deletion then failed while publishing state, despite the server having completed the mutation. The shared tests reproduced `invalid_projection:EmailAddress.emailAddress` and `invalid_projection:PhoneNumber.phoneNumber`; the packaged Swift test reproduced the email failure, and the Kotlin test failed at the same public deletion operation before the bundle update.

The shared `BaseResource` now skips resource hydration for a DELETE response explicitly marked `deleted: true`. The response's client is still applied by the existing fetch path. Full resource responses to DELETE, including client/session operations, retain their previous hydration path. A held deleted contact retains its last readable fields; this does not promise it can be mutated again or independently remove it from a collection when the server supplies no updated client.

The new Swift `ContactResourceTests` and Kotlin `ContactResourceTest` retain all three contact wrappers, delete each through the generated API, verify each updated user collection and held fields, and then execute another generated operation to confirm the owner remains usable. Source and native checks use deterministic HTTP fixtures. They establish no actual account deletion, phone delivery, provider consent, live upgrade, or platform-prompt outcome.

The replacement checks pass: the final shared embedded suite passed 224 tests, including all 11 focused contact/external-account tests, existing source resource suites passed 58 tests, and the complete native contract target passed 67 tests on macOS and 64 on the iOS simulator. The Android packaged contact test and all eleven existing packaged-core tests also pass on the arm64 API 36 emulator. Both native packages contain core revision `72d26867810ed582b9432efc6f4bca90591fd6e6` and bundle SHA `e2d7a061a98d574114bb2048e0d0a1948223fac298c29925f43764ec6290c18d`. These six reviewed contact/resource service files are retired with their deleted service implementations. Other legacy tests remain for their separate audits.
